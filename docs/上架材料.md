## 三、差异化卖点（提交描述用）

1. 全生命周期可视：原生 CoT 思考过程 + goal/todo 实时卡片 + workflow run/member/phase/log 文本流 + 压缩透明化
2. 断点续跑：会话持久化 + `autoResumeGoals` 重启后自动续跑活跃目标
3. 决策留痕：审批卡片回写决策人与结果 + `/audit` 会话审计
4. 会话全文检索：`/sessions <关键词>` 检索本聊天历史
5. 后台任务与子代理结算通知
6. 免公网回调（WebSocket 长连接）+ 扫码注册 + 编译产物直装
